# Mobile check-in confirmation motion

Fake auth and API data only, at 390px, 768px and 1440px. For each width, `save-before` shows the filled form before saving; `save-during` shows the immediate Today result with the tick fading in (controlled clock at 60ms); `save-after` shows its final opacity. Confirmation text and controls never wait for the tick. Reduced motion skips the animation, covered by native tests.
