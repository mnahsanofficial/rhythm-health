Use /design:research-synthesis to add this as round 3 in
docs/design/04-synthesis.md. Use /design:design-critique and
/design:ux-copy on every mobile screen in the main flow (Today,

Progress, History). For each screen, count the visible words now and

Principles to apply:
1. A text budget: at most one heading plus one short line per screen
   section. Everything else goes behind a tap ("Details", a sheet, or
   the next screen). No paragraphs on main screens.
2. Grey only for captions. Main content uses the full-contrast text
   token. Every caption still passes WCAG AA in light and dark.
3. Show state with icons, not sentences: a check for recorded, a dot
   for missed, a ring for progress.
4. One decision per screen.

## Step 2: build (small PRs against main, tests first)
